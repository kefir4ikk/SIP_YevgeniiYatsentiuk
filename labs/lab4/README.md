## Що реалізовано

1. **Аналіз стійкості:** нулі й полюси базової функції (аналітично та через `tf2zpk`), порівняння стійкої та нестійкої конфігурацій, імпульсні характеристики, верифікація розкладом на лишки (`residuez`) та огинаючою `2|r||p|^n`.
2. **Синтез фільтрів ФВЧ:** КІХ методом вікна (`firwin`, Хеммінг, 51 відлік) та НІХ Баттерворта 4-го порядку (`butter`, білінійне перетворення); АЧХ, ФЧХ, груповий час затримки; перевірка симетрії КІХ та формули АЧХ Баттерворта з попереднім викривленням частоти.
3. **Фільтрація зашумленого сигналу:** корекція затримки КІХ без циклічного зсуву, спектри на усталеному фрагменті без витоку (бін 40 та 180), придушення завади, збереження корисної складової, потужність шуму, SNR.
4. **Експорт результатів** у `data/` (CSV та JSON).

## Основні результати

**Стійкість базової системи:**

| Система | Нулі | Полюси | `\|p\|` | Висновок |
|---|:-:|:-:|:-:|---|
| Стійка (`a2 = 0.64`) | `-1` (подвійний) | `0.4 ± j0.6928` | 0.800 | стійка, `h[n] → 0` |
| Нестійка (`a2 = 1.25`) | `-1` (подвійний) | `0.4 ± j1.0440` | 1.118 | нестійка, `h[n] → ∞` |

**Порівняння синтезованих фільтрів:**

| Параметр | КІХ (FIR Hamming) | НІХ (IIR Butterworth) |
|---|---|---|
| Порядок / кількість коефіцієнтів | 50-й порядок, 51 коефіцієнт | 4-й порядок, 5 + 5 коефіцієнтів |
| Розташування полюсів | усі 50 у `z = 0` | 4 полюси, `\|p\|` = 0.2385 (×2), 0.6784 (×2) |
| Підсилення на `fc = 350` Гц | −6.02 дБ | −3.01 дБ |
| ФЧХ | строго лінійна | нелінійна |
| Груповий час затримки | 25 відліків = 20.83 мс (стала) | 1.7…3.2 відліку у смузі 400…600 Гц |
| Придушення `f1 = 100` Гц | −61.89 дБ | −54.96 дБ |
| Підсилення на 250 Гц | −61.73 дБ | −18.47 дБ |
| Збереження амплітуди `f2 = 450` Гц | 99.91 % | 99.64 % |
| SNR на виході (на вході −2.65 дБ) | 15.26 дБ (+17.9 дБ) | 15.06 дБ (+17.7 дБ) |
