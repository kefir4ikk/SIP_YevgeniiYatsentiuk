## Що реалізовано

0. **Блоки 1–5 методички** (скрипт `lab11_fft2d_edges.py`, розділ 3 ноутбука): тестова сцена `test_edge_scene.png`, спектри, ILPF / GLPF / GHPF, Собель та Шарр, Кенні в режимах [30, 80], [50, 150], [120, 220] та [60, 180] (варіант 2) з оцінкою за еталонним контуром.
1. **2D-ДПФ (плата):** власна реалізація `F = W f W` проти `numpy.fft.fft2`, рівність Парсеваля, `F(0,0)`, положення нульової частоти після `fftshift`, теорема зсуву, логарифмічний масштаб, радіальний профіль та частки енергії, обмін амплітуди й фази між двома сценами.
2. **Частотні фільтри:** ILPF, GLPF, GHPF; теорема згортки (GLPF ≡ гаусове розмиття з σx = N/(2πσf)), підсилення шуму проти теорії, ефект Гіббса (перерегулювання, період пульсацій, ширина краю), циклічність ДПФ-фільтрації.
3. **Градієнти:** `cv2.Sobel` та `cv2.Scharr` проти кореляції ядер у `scipy.ndimage`; підсилення шуму проти теорії; ізотропність на аналітичному краї під кутами 0–90°; порогування градієнта без NMS.
4. **Кенні:** власна реалізація (Собель, NMS за квантованим напрямом, подвійний поріг, 8-зв'язний гістерезис) проти `cv2.Canny`; чотири режими порогів; оцінка за еталонним контуром (допуск 2 px) із розподілом пікселів на TP, шовкографію та хибні.
5. **Додаткові дослідження:** користь гістерезису, розгортка `T_high`, попередня фільтрація ILPF / GLPF перед Кенні.
6. **Експорт результатів** у `data/` (PNG, CSV, JSON).
