## Що реалізовано

1. **Афінне перетворення:** матриця `M (2×3)` через `getRotationMatrix2D`, перевірка замкненою формулою та добутком матриць 3×3; `warpAffine` звірено з `scipy.ndimage.map_coordinates` та `PIL.Image.transform`; площа, паралельність, частка «дір» при прямому відображенні.
2. **Інтерполяція:** NEAREST, LINEAR, CUBIC, LANCZOS4 при двократному збільшенні з відомим еталоном (MSE, PSNR, ширина краю 10-90 %, ефект Гіббса, накопичення розмиття при поворотах, час).
3. **Гомографія:** власне розв'язання системи 8×8 (DLT), детермінант та число обумовленості, точки сходу, кути сторін, ручне зворотне відображення; випрямлення чотирма інтерполяціями з кількісною оцінкою (MSE, PSNR, зсув фазовою кореляцією).
4. **Афінна модель проти гомографії:** афінна спроба за трьома та чотирма точками.
5. **Експорт результатів** у `data/` (PNG, CSV, JSON).

## Основні результати

**Матриці перетворень:**

| Матриця | Значення |
|---|---|
| `M` (афінна 2×3) | `[[0.845723, −0.307818, 124.056095], [0.307818, 0.845723, −36.844259]]`, `det = 0.8100 = s²` |
| `H` (гомографія 3×3) | `[[1.085000, 0.306026, −219.7821], [−0.151882, 1.336562, −79.58617], [−2.7035e−4, 1.1923e−3, 1]]`, `det = 1.5666`, `cond = 4.40e4` |

**Перевірки:** `M` збігається із замкненою формулою та добутком 3×3; `warpAffine` проти `scipy.ndimage` — max 0.50, проти `PIL` — max 1.0 (рівні яскравості); `H_DLT` проти OpenCV — 2.8e−14; похибка опорних точок 1.1e−13 px; точки сходу `(7941, 962)` та `(413, −745)`.

|---|:-:|:-:|:-:|:-:|:-:|
