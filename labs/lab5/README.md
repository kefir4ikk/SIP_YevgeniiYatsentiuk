## Що реалізовано

1. **Числові характеристики:** білий шум та AR(1) через `scipy.signal.lfilter` (з відкиданням перехідного процесу), вибіркові середнє, дисперсія (`ddof=1`), СКВ, асиметрія, ексцес, гістограми з теоретичною щільністю Гаусса; ансамблеве моделювання Монте-Карло (1000 реалізацій) для перевірки стандартних похибок оцінок.
2. **АКФ та інтервал кореляції:** зсунена оцінка АКФ (через `signal.correlate`), перевірка прямим обчисленням, довірчий інтервал для білого шуму, похибка за формулою Бартлетта для AR(1), інтервал кореляції за рівнем `1/e` та оцінка `â` за Юлом-Волкером.
3. **СПМ за Вінером-Хінчіним:** теоретична СПМ, оцінка Велча та оцінка з АКФ (Блекман-Тьюкі).
4. **Кореляційне виявлення коду Баркера-7:** ВКФ з опорним сигналом, оцінка затримки за піком, ОСШ на вході та на виході, виграш обробки, ПБР.
5. **Статистика виявлення (Монте-Карло):** розподіл похибки затримки, поріг за ймовірністю хибної тривоги 1 %, ймовірність виявлення, залежність від вхідного ОСШ.
6. **Експорт результатів** у `data/` (CSV та JSON).
