Досліджуваний сигнал:

`s[n] = A1·sin(2π·f1/fs·n + φ1) + A2·cos(2π·f2/fs·n + φ2) + v[n]`, `v[n] ~ N(0, σ²)`

| Параметр | Значення |
|---|---|
| `fs` | 1200 Гц |
| `A1`, `f1`, `φ1` | 3.0 В, 200 Гц, π/6 |
| `A2`, `f2`, `φ2` | 0.10 В, 225 Гц, 0 |
| `σ_noise` | 0.04 В |
| Базове `N` | 256 |
| Частотний крок `Δf = fs/N` | 4.6875 Гц |
| `f1/Δf` | 42.667 (некратна: витік спектра) |
| `f2/Δf` | 48 (кратна: рівно бін 48) |
| `A1/A2` | 29.5 дБ |
| Когерентне `N` (кратне 48) | 240 (`Δf` = 5 Гц, `f1` — бін 40, `f2` — бін 45) |

## Що реалізовано

1. **Матричне ДПФ та бенчмарк:** власна реалізація `X = W_N·x` (блочна, з показником за модулем `N`), порівняння з `np.fft.fft` для `N` = 64, 256, 1024, 4096: час, прискорення відносно теорії `N/log2(N)`, максимальна похибка.
2. **Амплітудний та фазовий спектри** сигналу при `N = 256`; порівняння пікових значень, частот і фаз з істинними та теоретичними (поправка фази для некратної частоти).
3. **Витік спектра:** гармоніка `f1` при `N = 240` (40 періодів, кратно) та `N = 256` (42.667 періоду); частка потужності поза піком, втрати амплітуди; перевірка рівня витоку ядром Дирихле; відновлення амплітуд і фаз при когерентному `N = 240`.
4. **Віконний аналіз:** прямокутне, Ханна, Хеммінга, Блекмана; нормування на когерентне підсилення, виявлення слабкої гармоніки `f2`, чисельне визначення ширини головної пелюстки, рівня бічних пелюсток та ENBW.
5. **Експорт результатів** у `data/` (CSV та JSON).
