## Що реалізовано

1. **Моделі шумів:** гаусів шум із відсіканням до `[0, 255]` та імпульсний шум точної щільності (вибірка без повторень); верифікація виміряної MSE з теоретичною.
2. **Фільтри:** Box, Gauss, Median, Bilateral (OpenCV) із перевіркою кожного незалежною реалізацією (`sliding_window_view`, `scipy.ndimage`, пряма формула білатерального ядра).
3. **Метрики:** MSE та PSNR для всіх комбінацій фільтр × тип шуму; розклад похибки на однорідну зону та зону контурів.
4. **Чутливість до параметрів:** розмір вікна `K`, `σ` Гаусса, `σ_c` білатерального фільтра.
5. **Підвищення різкості:** ядро Лапласа, `I_sharp = I + k·I_lap`; вплив на шум, контури, залежність від `k`.
6. **Експорт результатів** у `data/` (PNG, CSV, JSON).

## Основні результати

**Модель шуму (виміряно):** гаусів шум — MSE 593.5 (не 625: відсікання до `[0, 255]`, очікувано 592.3); «сіль та перець» — рівно 8.00 % пікселів, MSE 1764.3 (теорія 1768.7).
